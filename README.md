# 🚀 3D 多人連線生存射擊遊戲 (3D Multiplayer Survival Shooter)

這是一個基於 **Three.js** 和 **Socket.io** 開發的網頁版第一人稱射擊 (FPS) 遊戲。玩家可以在一個開放的地圖中對抗波次襲來的敵人，並與其他線上玩家即時同步位置與戰況。

## 🎮 遊戲特色
*   **多人即時連線**：支援多名玩家在同一個地圖中移動、射擊與互動。
*   **波次生存系統**：敵人會以波次 (Waves) 形式出現，難度隨波次增加。
*   **經典武器**：配置標準自動步槍，具備穩定射速與傷害。
*   **流暢移動機制**：支援跳躍、滑行 (Slide) 以及縮放準心 (Zoom)。
*   **進階反饋**：子彈彈道流光、擊中閃爍、爆頭判定機制。

## ⌨️ 操作控制
*   **W / A / S / D**：移動角色
*   **滑鼠移動**：旋轉視角
*   **滑鼠左鍵**：開火射擊
*   **滑鼠右鍵**：瞄準縮放 (Zoom)
*   **R 鍵**：更換彈匣 (Reload)
*   **C 鍵**：快速滑行 (Slide) - 具備冷卻時間
*   **空白鍵 (Space)**：跳躍
*   **滑鼠滾輪**：快速切換武器

## 🚀 如何開始遊戲
### 1. 安裝環境
確保你的電腦已安裝 [Node.js](https://nodejs.org/)。

### 2. 下載依賴
在專案目錄下執行：
```bash
npm install
```

### 3. 啟動伺服器
執行以下指令啟動遊戲：
```bash
node server.js
```

### 4. 進入遊戲
開啟瀏覽器並輸入以下網址：
`http://localhost:3000`
