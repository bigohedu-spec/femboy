✨ 關於此專案

3D Survival Arena 是一個致力於將復古 Arena Shooter 體驗與現代網頁技術結合的開源實驗性專案。

🛠️ 技術棧 (Tech Stack)

Three.js (3D 渲染)
Node.js / Express
Socket.io (即時同步)
Web Audio API

📖 開發背景

本專案最初是為了測試大規模多人連線下的實體同步與 3D 碰撞效能。 目前已實裝完整的波次系統、經濟系統、武器解鎖機制以及基礎的多人對戰框架。
